# CTF & Vulnerable Machine Write-ups

Welcome to my cybersecurity practice repository.

This repository documents my journey in offensive security through vulnerable machines and Capture The Flag (CTF) challenges. My goal is to improve my penetration testing methodology by focusing on reconnaissance, enumeration, analysis, exploitation, and documentation.

> **Note:** These write-ups are intended for educational purposes and are based on intentionally vulnerable labs.

## Write-up Format

Each write-up typically includes:

- Objective
- Reconnaissance
- Enumeration
- Analysis
- Exploitation
- Privilege Escalation (if applicable)
- Lessons Learned

The emphasis is on documenting the reasoning behind each step rather than simply listing commands.
